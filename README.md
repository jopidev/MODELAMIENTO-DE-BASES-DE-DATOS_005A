# MODELAMIENTO-DE-BASES-DE-DATOS_005A

Este repositorio contiene las actividades semanales de la asignatura **Modelamiento de Bases de Datos (005A)**.  
Cada semana se desarrolla en una **rama distinta** (`s1`, `s2`, `s3`…), con el objetivo de mantener el progreso organizado.  

---

## Estructura del repositorio
- **main** → rama principal, sin trabajo directo.  
- **s1** → Semana 1: Aplicando conceptos de modelamiento inicial.  
  - `Exp1_S1_Grupo10.docx` → Formato de respuesta con capturas (MER y Bachman).  
  - `Exp1_S1_Grupo10.zip` → Proyecto generado en Oracle SQL Data Modeler.  

---

## Herramientas utilizadas
- **Oracle SQL Developer Data Modeler** → para la creación del MER y notación Bachman.  
- **Git & GitHub** → para control de versiones y entrega de las actividades.  

---

## Actividad Semana 1
**Caso BT&Airways**  
- Identificación de entidades: `PASAJERO`, `EMPLEADO`, `VUELO`, `RESERVA`.  
- Definición de atributos obligatorios, opcionales e identificadores únicos.  
- Asignación de tipos de datos (`VARCHAR2`, `DATE`, `NUMBER`).  
- Generación de:  
  - **Modelo Entidad–Relación (MER)** en notación Barker.  
  - **Modelo en notación Bachman**.  

---

## Entregables
- Capturas de ambos modelos en el formato de respuesta.  
- Archivos `.dmd` y subcarpeta comprimidos en `.zip`.  
- Documento Word subido a GitHub y entregado en AVA.

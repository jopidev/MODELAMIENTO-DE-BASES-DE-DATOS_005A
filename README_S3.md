# MODELAMIENTO-DE-BASES-DE-DATOS_005A - Semana 3

##  Actividad Sumativa - MER-E (Modelando jerarquías entre entidades)

**Caso:** Vivir Mejor - Residencias de Estadía Prolongada

En esta semana se desarrolla un **Modelo Entidad-Relación Extendido (MER-E)** que incorpora:
- Entidades fuertes y débiles del contexto.
- Supertipos y subtipos (con exclusividad).
- Relaciones con cardinalidad mínima y máxima.
- Jerarquías y relación recursiva (MÉDICO supervisa a MÉDICO).
- Atributos obligatorios, opcionales y únicos con tipos de datos apropiados.

##  Herramientas
- Oracle SQL Developer Data Modeler → para generar el MER (Barker) y Bachman (tipos de datos).
- GitHub → control de versiones, rama `s3`.

##  Entregables
- **Captura 1:** MER en notación Barker.
- **Captura 2:** MER-E en notación Bachman.
- Archivo `.dmd` + subcarpeta → comprimido en `.zip`.
- Documento Word (formato S3) con capturas y link a GitHub.
